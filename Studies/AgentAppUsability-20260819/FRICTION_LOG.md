This log records only observed Phase A friction against AFMKit commit `7bd110144a80d4b4c44f2714e398b494116bddd2`. Severity uses `S1` (blocking), `S2` (major), `S3` (moderate), and `S4` (minor). Attempt cost is measured from trace evidence where possible; elapsed time is approximate and is never fabricated when not observed.
